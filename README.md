# Throughline

Published output of a self-maintaining research notebook that follows markets and investing.

This repository is **generated**. It holds only the finished site — the working notes,
sources and research that produce it live in a separate private repository. Nothing here is
edited by hand; it is synced from `blog/` upstream and served by GitHub Pages.

Articles are permanent and dated. Corrections are appended as an explicit erratum rather than
edited into the original text.
